PrizmX 是一款面向 Apple 平台的代理客户端，以开源项目的形式开发。本政策说明 PrizmX 应用及本网站会处理哪些信息，以及这些信息的去向。

**简而言之**：PrizmX 没有账户，不进行数据分析，不投放广告，也不进行追踪。我们不运营任何从应用接收您数据的服务器。您的配置、设置和统计数据均保留在您的设备上。

## 本政策的适用范围

本政策适用于：

- **PrizmX 社区版**，即通过 GitHub 分发的免费开源 macOS 应用；
- **PrizmX App Store 版**，即通过 App Store 分发的 iOS 和 macOS 版本；以及
- 本网站。

上述两款应用合称“本应用”。“PrizmX”和“我们”均指 PrizmX 项目及其开发者。

## 我们收集的信息

本应用不会向我们发送任何个人信息、使用数据、崩溃报告或设备标识符。本应用不包含任何第三方分析、广告或崩溃报告 SDK，也无需注册账户。

您可以自行核实：PrizmX 社区版及其核心库的源代码已公开于 [GitHub](https://github.com/PrizmX)。

## 存储在您设备上的信息

为正常运行，本应用会将以下数据本地保存在您设备上其自身的存储空间中：

- 您导入的**配置与订阅**，包括服务器地址、凭据、订阅链接、规则和策略组；
- **设置**，例如出站模式，以及系统代理、TUN 和 Allow LAN 选项；
- **流量统计**：约 35 天的每日汇总和 24 个月的每月汇总，包括流量消耗最多的域名和应用；
- Inspector 中显示的**连接记录**：数量有限的近期连接列表，包含应用、主机、命中的策略、协议、时长和字节数。

除非您自行分享或备份，这些数据不会离开您的设备。您可以在应用中移除配置以删除这些数据，也可以将应用连同其数据一并删除。

在 macOS 上，PrizmX 社区版会读取本地进程信息，以显示每条连接由哪个应用发起。此过程仅在您的 Mac 上进行。

## 本应用发起的网络连接

除对您的流量进行路由外，本应用还会连接以下服务。这些服务均不由我们运营，各服务会依据其自身的隐私政策接收您的 IP 地址等标准请求信息。

- **您的代理服务器**。流量会发送至您配置中的服务器，这些服务器由您本人或您选择的服务商运营。这些运营方可依据其服务的工作方式查看您的连接。PrizmX 不提供代理服务器或订阅。
- **订阅更新**。配置从您添加的订阅链接下载。
- **延迟测试**。为测量节点延迟，本应用会通过各节点向测试 URL（默认为 `http://www.gstatic.com/generate_204`，或您配置中设置的 URL）发送小型 HTTP 请求。为测量路径延迟，本应用会与 `1.1.1.1`（Cloudflare）和 `223.5.5.5`（Alibaba Cloud DNS，即阿里云公共 DNS）建立 TCP 连接，并使用您的系统 DNS 解析器查询 `www.apple.com`。
- **外部 IP 查询**。PrizmX 社区版会显示您当前的公网 IP 地址及其大致位置和所属网络。为此，它会在您建立连接、切换节点或打开主页视图时请求 `api.ipify.org` 和 `ipwho.is`。
- **规则数据库**。如果您的配置使用 `GEOIP` 或 `GEOSITE` 规则，本应用会从 GitHub（MetaCubeX/meta-rules-dat）或备用来源 jsDelivr 下载 `geoip.metadb` 和 `geosite.dat` 数据库，并大约每周更新一次。

## 权限

本应用会请求添加 VPN 配置（Packet Tunnel）的权限。该权限仅用于在您的设备上按照您的规则对设备流量进行路由。在 macOS 上，当系统代理开启时，PrizmX 社区版还可更改系统的代理设置。

如果您开启 **Allow LAN**，您所在局域网中的其他设备即可使用您的代理端口。请仅在您信任的网络中开启此选项。

## HTTPS 解密

PrizmX 社区版不会解密或修改您的流量。如果 PrizmX App Store 版提供 HTTP 抓包、解密或重写功能，这些功能将默认关闭，需要您自行安装并信任证书，且仅会在您的设备上处理解密后的内容。

## 购买与 Apple

PrizmX App Store 版中的购买由 Apple 处理。我们不会获取您的支付信息、姓名或 Apple ID。Apple 向我们提供的是无法识别您身份的销售报告。

如果您已在设备设置中选择与应用开发者共享分析数据，Apple 可能会向我们提供 PrizmX App Store 版的崩溃报告和汇总的使用统计数据。我们仅将其用于修复问题。Apple 对这些数据的处理方式详见 [Apple 隐私政策](https://www.apple.com/legal/privacy/)。

## 本网站

本网站托管于 GitHub Pages。本网站不使用 Cookie、分析或追踪，也不加载任何第三方脚本或字体。GitHub 可能出于安全和运营目的记录访问者的 IP 地址，详见 [GitHub 隐私声明](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)。PrizmX 社区版的下载由 GitHub Releases 提供，同样适用该声明。

## 与我们联系

如果您通过电子邮件与我们联系，我们将收到您的电子邮件地址和您的消息。我们仅将其用于回复您，仅在此目的所需的期限内保留，且不会与他人共享。

## 您的选择与权利

由于我们不持有来自本应用的个人数据，您可以直接控制自己的数据：您可以在应用中查看或删除这些数据，也可以将应用连同其数据一并删除。我们不会出售或共享个人信息。对于您发送给我们的任何消息，您可以通过下方的联系地址要求查阅或删除该消息。根据您所在地的不同，您还可能有权向数据保护机构投诉。

## 儿童

本应用并非面向 13 岁以下的儿童，我们也不会在知情的情况下收集儿童的个人信息。

## 本政策的变更

当本应用或本政策发生变更时，我们将更新本页面及上方的“最后更新”日期。重大变更还将在版本发布说明中注明。
