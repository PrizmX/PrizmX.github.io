PrizmX は、オープンソースプロジェクトとして開発されている Apple プラットフォーム向けのプロキシクライアントです。本ポリシーでは、PrizmX のアプリおよび本ウェブサイトがどのような情報を取り扱い、その情報がどこに送られるのかを説明します。

**概要**：PrizmX には、アカウント、アナリティクス、広告、トラッキングのいずれもありません。私たちは、アプリからお客様のデータを受け取るサーバーを運営していません。お客様のプロファイル、設定、統計は、お客様のデバイス内にとどまります。

## 本ポリシーの対象

本ポリシーは、次のものに適用されます。

- **PrizmX コミュニティ版**（GitHub を通じて配布されている、無料のオープンソース macOS アプリ）
- **PrizmX App Store 版**（App Store を通じて配布されている iOS および macOS 向けのエディション）
- 本ウェブサイト

以下、これら 2 つのアプリを総称して「本アプリ」といいます。「PrizmX」および「私たち」は、PrizmX プロジェクトとその開発者を指します。

## 収集する情報

本アプリは、個人情報、利用データ、クラッシュレポート、デバイス識別子を一切私たちに送信しません。また、本アプリにはサードパーティ製のアナリティクス、広告、クラッシュレポートの SDK は一切含まれておらず、アカウントも必要ありません。

このことは、お客様ご自身で確認できます。PrizmX コミュニティ版とそのコアライブラリのソースコードは、[GitHub](https://github.com/PrizmX) で公開されています。

## お客様のデバイスに保存される情報

本アプリは、動作のために、以下のデータをお客様のデバイス上にある本アプリ専用のストレージ内にローカルで保持します。

- お客様が読み込んだ**プロファイルとサブスクリプション**（サーバーアドレス、認証情報、サブスクリプション URL、ルール、ポリシーグループを含む）
- **設定**（アウトバウンドモード、システムプロキシ、TUN、Allow LAN の各オプションなど）
- **トラフィック統計**：約 35 日分の日別合計と 24 か月分の月別合計（最も多くのトラフィックを使用したドメインとアプリを含む）
- Inspector に表示される**接続履歴**：件数を限った最近の接続の一覧（アプリ、ホスト、マッチしたポリシー、プロトコル、接続時間、バイト数を含む）

これらのデータは、お客様ご自身が共有またはバックアップしない限り、お客様のデバイスの外に出ることはありません。これらのデータは、本アプリでプロファイルを削除するか、本アプリをそのデータとともに削除することで消去できます。

macOS では、PrizmX コミュニティ版は、各接続をどのアプリが開始したかを表示するために、ローカルのプロセス情報を読み取ります。この処理はお客様の Mac 上でのみ行われます。

## 本アプリが行うネットワーク接続

本アプリは、お客様のトラフィックのルーティングとは別に、以下のサービスに接続します。これらはいずれも私たちが運営するものではなく、各サービスは、それぞれのプライバシーポリシーに基づき、お客様の IP アドレスなどの標準的なリクエスト情報を受け取ります。

- **お客様のプロキシサーバー**。トラフィックは、お客様のプロファイルに含まれるサーバーに送信されます。これらのサーバーは、お客様ご自身またはお客様が選んだプロバイダーによって運営されています。その運営者は、それぞれのサービスの仕組みに応じて、お客様の接続を見ることができます。PrizmX は、プロキシサーバーやサブスクリプションを提供していません。
- **サブスクリプションの更新**。プロファイルは、お客様が追加したサブスクリプション URL からダウンロードされます。
- **遅延テスト**。ノードの遅延を測定するため、本アプリは各ノードを経由して、テスト用 URL（デフォルトは `http://www.gstatic.com/generate_204`、またはお客様のプロファイルで設定された URL）に小さな HTTP リクエストを送信します。経路の遅延を測定するため、本アプリは `1.1.1.1`（Cloudflare）および `223.5.5.5`（Alibaba Cloud DNS）への TCP 接続を開き、お客様のシステムの DNS リゾルバを使って `www.apple.com` を名前解決します。
- **外部 IP の照会**。PrizmX コミュニティ版は、お客様の現在のパブリック IP アドレスと、そのおおよその所在地およびネットワークを表示します。そのために、お客様が接続したとき、ノードを切り替えたとき、または Home 画面を開いたときに、`api.ipify.org` と `ipwho.is` にリクエストを送信します。
- **ルールデータベース**。お客様のプロファイルで `GEOIP` または `GEOSITE` ルールを使用している場合、本アプリは `geoip.metadb` および `geosite.dat` データベースを GitHub（MetaCubeX/meta-rules-dat）から、またはフォールバックとして jsDelivr からダウンロードし、約 1 週間に 1 回更新します。

## 権限

本アプリは、VPN 構成（Packet Tunnel）を追加するための許可を求めます。この構成は、お客様のデバイス上で、お客様のルールに従ってデバイスのトラフィックをルーティングするためにのみ使用されます。macOS では、PrizmX コミュニティ版は、システムプロキシがオンの間、システムのプロキシ設定を変更することもできます。

**Allow LAN**をオンにすると、ローカルネットワーク上のほかのデバイスがお客様のプロキシポートを使用できるようになります。信頼できるネットワークでのみオンにしてください。

## HTTPS の復号

PrizmX コミュニティ版は、お客様のトラフィックを復号または改変しません。PrizmX App Store 版で HTTP のキャプチャ、復号、書き換えが提供される場合、これらの機能はデフォルトでオフになり、お客様ご自身で証明書をインストールして信頼する必要があり、復号された内容はお客様のデバイス上でのみ処理されます。

## 購入と Apple

PrizmX App Store 版での購入は、Apple によって処理されます。私たちが、お客様の支払い情報、氏名、Apple ID を受け取ることはありません。Apple は、お客様を特定しない売上レポートを私たちに提供します。

お客様がデバイスの設定で App デベロッパと解析データを共有することを選択している場合、Apple は PrizmX App Store 版のクラッシュレポートと集計された使用状況の統計を私たちに提供することがあります。私たちは、これらを問題の修正のためにのみ使用します。Apple によるこのデータの取り扱いについては、[Apple のプライバシーポリシー](https://www.apple.com/legal/privacy/)に記載されています。

## 本ウェブサイト

本ウェブサイトは GitHub Pages でホストされています。Cookie、アナリティクス、トラッキングは一切使用しておらず、サードパーティ製のスクリプトやフォントも読み込みません。[GitHub プライバシーステートメント](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)に記載のとおり、GitHub はセキュリティおよび運用のために、訪問者の IP アドレスを記録することがあります。PrizmX コミュニティ版のダウンロードは、同じステートメントのもとで GitHub Releases から提供されます。

## 私たちへのお問い合わせ

お客様が私たちにメールを送信した場合、私たちはお客様のメールアドレスとメッセージを受け取ります。私たちは、これらを返信のためにのみ使用し、そのために必要な期間に限り保持し、共有することはありません。

## お客様の選択と権利

私たちは本アプリに由来する個人データを保有していないため、お客様はご自身のデータを直接管理できます。本アプリ内でデータを確認または削除することも、本アプリをそのデータとともに削除することもできます。私たちは、個人情報を販売または共有しません。お客様が私たちに送信したメッセージについては、下記の連絡先を通じて、そのアクセスまたは削除を求めることができます。お住まいの地域によっては、データ保護機関に苦情を申し立てる権利を有する場合もあります。

## 子ども

本アプリは 13 歳未満の子どもを対象としておらず、私たちが子どもから個人情報を故意に収集することはありません。

## 本ポリシーの変更

本アプリまたは本ポリシーに変更があった場合、私たちは本ページおよび上記の「最終更新日」を更新します。重要な変更については、リリースノートにも記載します。
