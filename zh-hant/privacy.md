PrizmX 是適用於 Apple 平台的代理用戶端，以開源專案的形式開發。本政策說明 PrizmX App 與本網站會處理哪些資訊，以及這些資訊的去向。

**簡而言之**：PrizmX 不設帳號、不投放廣告，也不進行追蹤。PrizmX 社群版會傳送匿名使用資料（例如 App 啟動次數與版本），協助我們了解 App 的使用情形。您可以在設定中關閉此功能。您的設定檔、設定與統計資料均保留在您的裝置上。

## 本政策的適用範圍

本政策適用於：

- **PrizmX 社群版**，即透過 GitHub 發行的免費開源 macOS App；
- **PrizmX App Store 版**，即透過 App Store 發行的 iOS 與 macOS 版本；以及
- 本網站。

上述兩款 App 以下合稱「本 App」。「PrizmX」與「我們」均指 PrizmX 專案及其開發者。

## 我們收集的資訊

本 App 不需要帳號，也未內含任何廣告 SDK。PrizmX App Store 版不會向我們傳送任何個人資料、使用資料、當機報告或裝置識別碼，也未內含任何第三方分析或當機回報 SDK。

### PrizmX 社群版中的匿名使用資料

PrizmX 社群版使用 [PostHog](https://posthog.com) 收集匿名使用資料。這些資料讓我們了解有多少人使用本 App、目前使用的是哪些版本與 macOS 版本，以及某個版本是否造成問題。此功能預設為開啟。您可以隨時在 **Settings → Privacy → Share Anonymous Usage Data** 中將其關閉。關閉期間，不會傳送任何資料。

開啟時，App 會在以下時機傳送事件：啟動、安裝或更新時；執行期間每天一次；開啟或關閉 TUN、系統代理時；以及開啟或移至背景時。每個事件包含：

- 由 App 產生的隨機識別碼，與您的姓名、電子郵件地址或 Apple ID 無關聯；
- App 的版本類型、版本號碼、建置編號與套件識別碼（Bundle ID）；
- TUN 與系統代理是否開啟；
- 您的 Mac 機型、macOS 版本、螢幕尺寸、語言、時區，以及是否正在使用 Wi-Fi。

事件不包含您的設定檔、訂閱、伺服器位址、認證資訊、規則、您造訪的網域或使用的 App、您的流量或連線記錄。如同任何伺服器，PostHog 會在每次請求中收到您的 IP 位址，並可能據此推估您的大致位置。PostHog 會依據 [PostHog 隱私權政策](https://posthog.com/privacy)將這些資料儲存於美國。我們僅將其用於改善 PrizmX，不會出售這些資料，也不會將其用於廣告。

您可以自行驗證：PrizmX 社群版及其核心程式庫的原始碼均公開於 [GitHub](https://github.com/PrizmX)。

## 儲存於您裝置上的資訊

為正常運作，本 App 會將下列資料保存在您裝置本機上、其自身的儲存空間內：

- 您匯入的**設定檔與訂閱**，包括伺服器位址、認證資訊、訂閱連結、規則與策略群組；
- **設定**，例如連出模式、系統代理、TUN 與 Allow LAN 等選項；
- **流量統計**：約 35 天的每日總量與 24 個月的每月總量，包括流量用量最高的網域與 App；
- Inspector 中顯示的**連線記錄**：數量有限的近期連線清單，內容包括 App、主機、符合的策略、協定、持續時間與位元組數。

除非您自行分享或備份，這些資料絕不會離開您的裝置。您可以在 App 中移除設定檔，或將 App 連同其資料一併刪除，以刪除這些資料。

在 macOS 上，PrizmX 社群版會讀取本機程序資訊，以顯示每條連線是由哪個 App 發起。此作業僅在您的 Mac 上進行。

## 本 App 建立的網路連線

除了轉送您的流量之外，本 App 還會連線至下列服務。這些服務均非由我們營運，且各服務會依其自身的隱私權政策，接收您的 IP 位址等標準請求資訊。

- **您的代理伺服器**。流量會傳送至您設定檔中的伺服器，這些伺服器由您本人或您選擇的供應商營運。這些營運者能夠看到您的連線，具體情形視其服務的運作方式而定。PrizmX 不提供代理伺服器或訂閱。
- **訂閱更新**。設定檔會從您新增的訂閱連結下載。
- **延遲測試**。為測量節點延遲，本 App 會透過各節點向測試網址（預設為 `http://www.gstatic.com/generate_204`，或您設定檔中指定的網址）傳送小型 HTTP 請求。為測量路徑延遲，本 App 會與 `1.1.1.1`（Cloudflare）及 `223.5.5.5`（Alibaba Cloud DNS）建立 TCP 連線，並使用您的系統 DNS 解析器查詢 `www.apple.com`。
- **外部 IP 查詢**。PrizmX 社群版會顯示您目前的公用 IP 位址，以及其大致位置與所屬網路。為此，PrizmX 社群版會在您連線、切換節點或開啟首頁畫面時，向 `api.ipify.org` 與 `ipwho.is` 發出請求。
- **使用資料**。若匿名使用資料為開啟狀態，PrizmX 社群版會依上文所述將其傳送至 PostHog（`us.i.posthog.com`）。
- **規則資料庫**。若您的設定檔使用 `GEOIP` 或 `GEOSITE` 規則，本 App 會從 GitHub（MetaCubeX/meta-rules-dat）下載 `geoip.metadb` 與 `geosite.dat` 資料庫（或以 jsDelivr 作為備援來源），並約每週更新一次。

## 權限

本 App 會請求新增 VPN 設定（Packet Tunnel）的權限。此權限僅用於在您的裝置上，依照您的規則轉送裝置的流量。在 macOS 上，PrizmX 社群版於系統代理開啟期間，亦可變更系統代理設定。

若您開啟 **Allow LAN**，區域網路中的其他裝置即可使用您的代理連接埠。請僅在您信任的網路上開啟此功能。

## HTTPS 解密

PrizmX 社群版不會解密或修改您的流量。若 PrizmX App Store 版提供 HTTP 擷取、解密或改寫功能，這些功能將預設為關閉，須由您自行安裝並信任憑證，且僅會在您的裝置上處理解密後的內容。

## 購買與 Apple

PrizmX App Store 版內的購買交易由 Apple 處理。我們不會收到您的付款資訊、姓名或 Apple ID。Apple 會向我們提供無法識別您身分的銷售報告。

若您已在裝置設定中選擇與 App 開發者分享分析資料，Apple 可能會向我們提供 PrizmX App Store 版的當機報告與彙總使用統計資料。我們僅將其用於修正問題。Apple 對這些資料的處理方式，詳見 [Apple 隱私權政策](https://www.apple.com/legal/privacy/)。

## 本網站

本網站託管於 GitHub Pages。本網站不使用 Cookie、分析或追蹤技術，也不載入任何第三方指令碼或字型。GitHub 可能基於安全與營運目的記錄訪客的 IP 位址，如 [GitHub 隱私權聲明](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)所述。PrizmX 社群版的下載檔案由 GitHub Releases 提供，同樣適用該聲明。

## 與我們聯絡

若您以電子郵件與我們聯絡，我們會收到您的電子郵件地址及訊息內容。我們僅將其用於回覆您，僅在回覆所需期間內保留，且不會分享這些資訊。

## 您的選擇與權利

本 App 不會向我們傳送個人資料，因此您可直接掌控自己的資料：您可以在 App 中檢視或刪除資料，或將 App 連同其資料一併刪除。在 PrizmX 社群版中，您可以隨時在設定中關閉匿名使用資料。我們不會出售或分享個人資料。對於您寄給我們的任何訊息，您可透過下方的聯絡地址要求我們提供查閱或予以刪除。視您的居住地而定，您可能也有權向資料保護主管機關提出申訴。

## 兒童

本 App 並非以未滿 13 歲的兒童為對象，我們也不會在知情的情況下收集兒童的個人資料。

## 本政策的變更

當本 App 或本政策有所變更時，我們會更新本頁面及上方的「最後更新」日期。重大變更亦會在發行說明中註明。
